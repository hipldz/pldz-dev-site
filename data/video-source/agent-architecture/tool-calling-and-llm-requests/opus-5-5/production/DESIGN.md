# 设计说明 · 3 分钟版

影片按《ToolCalling 和 Request 是一对一的吗？》的叙事展开。屏幕文字全文在 `src/film/captions.json`；运行 `npm run srt` 可生成外挂字幕 `production/film.zh-CN.srt`。

## 四条原则

1. **原文的叙事和口吻不动。** 保留"我"这条线：做 WebUI lite → 发现又长又重复 → 猜想 → 和 GPT 对线 → 结论 → 背书 → 自己怎么建模 → 回到自己的 WebUI。口头禅原样保留："其实就是和 GPT 对线""时间宝贵，先给结论""这里要看背书的东西了……""就看这三个变量得了""混为一谈啊"。
2. **画面要自己能讲清楚。** 屏幕文字与旁白共用时间轴，概念让画面演出来：计数器跳 3 下 vs 跳 1 下；三条跑道 b → c → a 先后到达；连线从乱麻变成三根对上的线。
3. **一张画布、一台摄像机。** 没有章节页和母版；换段落就是镜头移动。离开的区域保留最终状态并变暗，长距离飞行时能看到前面讲过的东西。
4. **同一批对象贯穿全片。** S3 例子里的 Response #1–#3 和 call_001–005：S4 展开成 JSON，S7 原地重排成数据模型，S8 拿来跑并发。

## 视觉规范

- 深色背景，点阵网格锁定在画布上（镜头移动时能感到空间在走），柔光颜色随段落缓慢变化，加暗角和颗粒。
- 卡片统一用玻璃质感：半透明渐变、1px 描边、大投影；关键时刻用同色外发光强调。
- **颜色只表达含义**：紫 Turn · 琥珀 HTTP/Request · 蓝 Response/Generation · 绿 Tool Call · 红 注意/错误。蓝和绿取自官方 Trace 截图里 `POST /v1/responses` 和工具的图标颜色。
- **动效按含义区分**：模型产出的东西从卡片里弹出（带回弹）；应用执行沿跑道滑动；数据回传沿弧线流回；镜头缓入缓出，长距离飞行时先拉远再推近。
- 字体：无衬线（苹方 / 微软雅黑 / Noto Sans CJK），代码用等宽字体（JetBrains Mono / Consolas）。
